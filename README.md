# Creator Hub

Alle Werkzeuge für Content Creator an einem Ort: Videoschnitt, MP3-Schneider, Datei-Umwandler, KI-Upscaler und mehr.

## Herunterladen

Die neueste Version findest du unter **[Releases](https://github.com/zSpicyy/Creator-Hub/releases/latest)**:

| System | Datei |
|---|---|
| Windows | `Creator-Hub-Setup.exe` |
| Linux | `Creator-Hub-x86_64.AppImage` |
| macOS (Apple-Chip M1–M4) | `Creator-Hub-macOS-AppleSilicon.zip` |
| macOS (Intel) | `Creator-Hub-macOS-Intel.zip` |

Einmal installieren – danach kommen Updates automatisch über die App.
Jedes Update ist signiert; die App installiert nur Dateien, die echt von Creator Hub stammen.
